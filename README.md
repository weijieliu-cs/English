# 英语系统学习指南

面向**中文母语自学者**的英语学习资料库。用中文理解方法，用英语完成练习，逐步建立听、说、读、写能力。

适合零基础、基础薄弱，或学过多年但缺少实际使用经验的学习者。默认以日常交流和自主阅读为目标；备考、留学、工作需求可以在此基础上增加专项训练。

## 从这里开始

1. 阅读 [开始学习](docs/00-getting-started.md)，确定每天能投入的时间。
2. 完成 [起点自测](docs/01-self-assessment.md)，保存自己的听说读写样本。
3. 根据 [学习路线](docs/02-learning-roadmap.md) 选择阶段，填写 [学习档案模板](templates/learning-profile.md)。
4. 从 [12 周实践计划](plans/12-week-plan.md) 的第 1 周开始，每周留下可回看的作品。

**今天只有 15 分钟？** 读 [第一份练习示例](notes/examples/first-study-note.md)，大声读出短文，合上文本说 3 句话，再写下自己的版本。

## 每天怎么学

以 30 分钟为例：**复习 5 分钟 → 听读 10 分钟 → 说写 10 分钟 → 记录 5 分钟**。当天围绕同一个小主题展开，不必七个模块各学一遍。

每周完成 5 次常规练习、1 次复盘，另留 1 天休息或补漏。第 4、8、12 周用难度相近的新材料复测。时间分配和进度均可调整，不承诺固定期限达到某个等级。

## 文件怎么放

```text
english/
├── README.md                 # 总入口
├── docs/                     # 入门、自测、路线、方法、常见问题
├── skills/                   # 发音、词汇、语法、听说读写训练
├── plans/                    # 12 周实践计划
├── resources/                # 精选学习资源与 GitHub 参考来源
├── templates/                # 学习档案、日记、周复盘、笔记、错题、词汇表
├── notes/                    # 自己的知识笔记与完整练习示例
└── progress/                 # 学习档案、每日记录和阶段复测
```

复制模板后再填写，具体规则见 [笔记说明](notes/README.md) 和 [进度记录说明](progress/README.md)。正文以中文说明为主，英文例句配必要的中文解释；文件名使用英文，便于链接和检索。直接使用 Markdown 阅读器或 GitHub 即可，无需安装依赖。
