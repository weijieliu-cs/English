# 起点自测

[返回首页](../README.md) · [下一步：学习路线](02-learning-roadmap.md)

本页用于选择学习材料和保存起点，**不用于判定正式 CEFR 等级或换算考试分数**。听说读写可能处于不同水平，分别记录更有用。

## 先了解等级

CEFR 是描述语言能力的框架，常用 A1、A2、B1、B2、C1、C2 表示不同阶段。下面是便于选材的简要概括，详细能力描述见 [British Council 官方说明](https://learnenglish.britishcouncil.org/level/understand-your-english-level)。

| 等级 | 大致能完成的任务 |
| --- | --- |
| A1 | 使用熟悉的基本表达，介绍自己、询问简单个人信息 |
| A2 | 在常见生活情境中进行简单直接的信息交流 |
| B1 | 理解熟悉主题，描述经历，写简单连贯的文字 |
| B2 | 理解较复杂材料的主要内容，较流畅交流并解释观点 |
| C1—C2 | 在复杂社交、学术或专业场景中更灵活、准确地理解和表达 |

在线测试可以辅助选择材料，但只测语法、词汇或阅读的结果不能代表口语和听力。也不要用“背了多少词”代替实际任务表现。

## 做一次约 30 分钟的基线记录

准备两种材料：一段带文本的短音频、一篇带理解题的短文。先从 [British Council](../resources/README.md) 的 A1 或你认为合适的级别试起；过易或过难都可以更换，并记录原因。

| 技能 | 任务 | 记录什么 |
| --- | --- | --- |
| 听力，约 7 分钟 | 选约 1 分钟音频，不看文本听两次，再核对 | 主旨、听懂的细节、是否依赖文本、漏听原因 |
| 口语，约 5 分钟 | 不照稿介绍自己，或描述昨天做了什么；再回答两个相关问题 | 实际时长、停顿、借助中文的地方、能否回应问题 |
| 阅读，约 8 分钟 | 选一篇约 150—300 词短文，先不查词，概括并答题 | 大意、答对题数、卡住的句子、查词次数 |
| 写作，约 10 分钟 | 写自我介绍或日常安排，目标 5—8 句，有余力再写一段 | 原始文本、是否靠翻译、句子结构和信息是否清楚 |

零基础：材料缩短到几句话；能说一个短语、写一个句子也保留。较熟练者：选择较高级别材料，改做经历叙述、观点表达或实际工作任务。记录材料级别与长度，避免把不同难度的成绩直接比较。

第一次保留不查词、不翻译的版本；随后可以借助工具完成第二版。把两版分开，才能区分独立能力和获得帮助后的表现。

## 给每项能力标记状态

这里的状态仅供本项目追踪使用，不对应 CEFR 分数。

- **需要帮助**：主要依靠译文、提示或照稿才能完成。
- **部分独立**：能独立完成部分任务，仍有影响理解的缺口。
- **基本独立**：能完成主要任务，表达和细节仍需改进。

为每项状态附一句证据，例如：“听出是改约时间，但没听清星期几。”暂时无法做的任务标为“未完成”，不要为了打分猜测结果。

## 根据结果选入口

| 观察到的情况 | 建议入口 |
| --- | --- |
| 字母、常用词和简单句还很陌生 | 路线阶段一；先练基础发音和常用句 |
| 能理解简单短文，但很难听懂或开口 | 路线阶段二；把短篇听读与简单回应配对 |
| 能独立介绍和描述生活，但长材料或追问困难 | 路线阶段三；练复述、对话和段落组织 |
| 能处理一般内容，需要工作或学术表达 | 路线阶段四；增加具体领域任务 |

以上是训练入口，不是等级认证。阅读强、口语弱时可以分别选不同阶段的材料。

## 每 4 周怎么复测

复制 [学习档案模板](../templates/learning-profile.md) 的复测表，保存到 [进度目录](../progress/README.md)。

1. 使用**同级别、相近长度与题型的新材料**，尽量保持时间和工具使用条件一致。
2. 仍保留无辅助版本，比较任务完成度和具体错误。
3. 再回看旧材料，观察是否能更轻松理解；这项结果单独记录，避免把熟记当成迁移能力。
4. 选定下一轮最需要改善的一项能力。
