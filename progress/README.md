# 学习进度与复盘

[返回首页](../README.md) · [12 周计划](../plans/12-week-plan.md)

这里保存你实际做过什么、遇到什么问题，以及下一步如何调整。文件按需要创建，模板和演示笔记不计入真实完成记录。

| 记录 | 从哪里复制 | 建议保存位置 |
| --- | --- | --- |
| 学习目标与听说读写基线 | [学习档案模板](../templates/learning-profile.md) | `progress/learning-profile.md` |
| 每日练习 | [每日记录模板](../templates/daily-log.md) | `progress/daily/YYYY-MM-DD.md` |
| 周复盘 | [周复盘模板](../templates/weekly-review.md) | `progress/weekly/YYYY-Www.md` |
| 第 4、8、12 周复测 | 学习档案中的阶段复测表 | 追加到 `progress/learning-profile.md` |
| 值得长期保留的笔记和作品 | [学习笔记模板](../templates/study-note.md) | `notes/` 下对应主题目录 |

## 第一次使用

1. 复制学习档案，写下真实目标和可用时间。
2. 按 [起点自测](../docs/01-self-assessment.md) 留下样本，记录是否用过工具或文本。
3. 当天练习后创建一份每日记录，链接实际作品。
4. 每周只做一次简短复盘，决定下周一个调整。

不必只看连续打卡天数。更值得回看的证据包括：同级别新材料能否理解、表达能否被听懂、是否减少对译文的依赖、重复错误能否在新任务中避免。

未完成就如实记录。中断后可以缩短任务再开始，保留前后的记录，方便观察什么安排更适合自己。
