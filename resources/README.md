# 学习资源导航

[返回首页](../README.md) · [GitHub 项目参考](github-projects.md)

先选一套主材料、一种词典和一种复习方式，连续使用两周，再根据完成情况调整。中文解释主要看本项目和下方 GitHub 指南；外部课程大多为英文，可以从低一级材料开始。

## 按用途选一套起步组合

| 情况 | 推荐先试 | 每天做什么 |
| --- | --- | --- |
| 刚开始，中文解释更容易理解 | 本项目基础模块 + 一套带音频的入门课程 | 读懂几句、听示范、替换成自己的信息 |
| 能读简单句，听说困难 | British Council 对应级别资源或 VOA 入门课程 | 短片段精听 + 自己口述几句 |
| 想把语法用到句子中 | 本项目语法页 + Cambridge 短练习 | 做题后用同一结构写自己的句子 |
| 已有基础，需要自主阅读 | 同级分级阅读，逐步加入兴趣内容 | 读主旨、记少量词块、做简短总结 |
| 有考试目标 | 目标考试的官方说明和样题，另外建立专项计划 | 按题型练习，并继续保留日常输入输出 |

入门教材如果已经有适合的正版课程，可以继续使用。优先保留有顺序、有音频、有练习反馈的内容，不必因为这份列表换掉正在有效使用的材料。

## 选材检查表

- [ ] 难度合适：能大致理解，不需要逐句翻译才能继续。
- [ ] 支持练习：音频有文本，或阅读有问题、答案等反馈。
- [ ] 长度可控：今天能完成一个片段或一个明确任务。
- [ ] 来源清楚：能找到作者、机构或官方发布入口。
- [ ] 适合自己：主题愿意继续学，访问方式和预算可以接受。

来源失效时，先换同级别、相近主题和形式的材料；已学内容仍可用自己的摘要与错题复习。下载和转存前遵守原站使用条件，项目中优先记录链接和自己的笔记。

## 新增资源格式

只在实际试用后增加主推荐，至少写明：

```text
名称与官方链接：
适合的学习阶段或技能：
一次怎样练习：
是否有音频、文本、练习或答案：
费用与账号要求：
语言、访问限制与可替代材料：
核对日期与实际核对范围：
```

更多候选材料可以从 [GitHub 项目参考](github-projects.md) 查找，不把尚未试用的全部资源直接变成每日任务。
