# 02 · 词汇

[返回首页](../README.md) · [上一模块：发音](01-pronunciation.md) · [下一模块：语法](03-grammar.md)

目标：遇到一个词时能在语境中理解，需要表达时能想起合适的搭配。

## 每个词至少关联一个场景

不要只记 `help = 帮助`。试着记录：

| 项目 | 示例 |
| --- | --- |
| 词或词块 | `ask for help` |
| 词性或结构 | 动词短语：`ask for + 所需事物` |
| 当前语境含义 | 请求帮助 |
| 自己的例句 | `I ask for help when I get stuck.` |
| 发音 | 听词典音频，必要时记音标和重音 |
| 来源 | 材料标题、链接、页码或音频时间点 |
| 复习情况 | 能否遮住答案说出表达、换情境造句 |

先记当前最需要的词义，不必一次抄完所有释义。词根词缀可以辅助联想，但具体词义、搭配和发音仍应核对。

## 每天怎么选词

从当天材料中选 3—5 个：妨碍理解、反复出现，或自己近期会用到的词。优先选 `make a plan`、`on time` 这类能放回句子的表达。

已有单词书可以作为补充；每天也要留一点真实听读，把词和实际语境连接起来。

## 两种回忆练习

- **理解卡**：看到 `I asked for help.`，说出大意并读出句子。
- **表达卡**：看到“遇到困难时，我会请求帮助”，尝试说英文，再核对参考表达。

表达卡可以有多种正确答案，不要求逐字复现。一次只检查一个知识点；卡片过长时，改成短句或填空。

手动记录使用 [词汇 CSV 模板](../templates/vocabulary.csv)。它是通用表格，不是特定软件的卡组；用表格软件打开时选择 UTF-8 编码。导入其他工具前，按该工具说明映射字段。

## 复习节奏

先复习旧词，再加新词。用 [学习方法](../docs/03-study-methods.md) 中的间隔建议或 [Anki](https://apps.ankiweb.net/) 的安排即可。答不出来时先重新理解例句，再缩短下次复习间隔；连续复习仍无用的冷僻词可以移出当前列表。

## 小练习

用 `make a plan`、`ask for help`、`on time` 各写一句与自己有关的话。然后遮住短语，根据场景重新说：

1. 你要安排周末做什么。
2. 你遇到不懂的问题。
3. 你答应按时到达。

参考表达（答案不唯一）：

1. `I'll make a plan for the weekend.`（我会安排周末计划。）
2. `I'll ask for help.`（我会请求帮助。）
3. `I'll be there on time.`（我会按时到。）

第二天换一个场景再用一次，比只确认“我看懂了”更能发现是否会用。
