# 04 · 听力

[返回首页](../README.md) · [上一模块：语法](03-grammar.md) · [下一模块：口语](05-speaking.md)

目标：先听懂关键信息，再逐步提高细节理解和对自然语流的反应。

## 按原因选练法

| 发生了什么 | 先做什么 |
| --- | --- |
| 看文本也不懂 | 补关键词和句子结构，或换更容易的材料 |
| 看文本懂，听不出词 | 选短片段做声音与词形对应，检查弱读、词尾和重音 |
| 每个词大致听到，整句反应不过来 | 缩短片段，按意群理解，减少逐词翻译 |
| 一走神就丢失主线 | 缩短材料，先带着一个问题听，再逐步延长 |
| 熟悉材料能懂，换材料就不懂 | 增加同级别新材料，检验迁移，避免只背熟原文 |

## 一轮精听

选 30—90 秒、带准确文本的音频。初学者可以只用 1—3 句。

1. 不看文本听一次，只记录主旨。
2. 再听一次，写关键词或回答两个问题。
3. 对照文本，标出漏听位置，判断是哪类障碍。
4. 只处理最关键的 10—20 秒，听一句、停一句，必要时短暂降速。
5. 回到正常语速，不看文本重听；用一句英文或中文概括。

听写只用于定位障碍，不必把所有听力材料逐字抄完。中文概括可以检查理解，英文复述则同时练输出。

## 三问记录法

听完回答：

- 谁在谈什么？
- 最关键的两个细节是什么？
- 哪一处不确定，需要核对？

例：一段改约时间的对话，重点可能是新日期、时间和地点。把 `Thursday` 听成 `Tuesday` 就应记录为关键信息错误，而不只写“听懂了一半”。

## 材料选择

优先使用 [British Council 分级资源](https://learnenglish.britishcouncil.org/free-resources)、[VOA Learning English](https://learningenglish.voanews.com/) 中带文本的适合材料。挑选及核对范围见 [资源导航](../resources/README.md)。

每周保留一点不查每个词的轻松听力，检查能否跟住内容。只有完全依赖中文字幕才能理解时，可先改用较低难度材料。

## 一周完成标准

保存 2—3 次短片段练习，并选一份同级别新材料检查主旨和细节。记录是否使用文本、播放次数、片段长度与错误原因；比较时保持条件相近。

听完可以直接进入 [口语训练](05-speaking.md)，用同一份材料做简短复述。
