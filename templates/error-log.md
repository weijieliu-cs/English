# 错误与改进记录

> 模板：复制到 `notes/errors.md`。只记录自己真实出现过、值得再次练习的问题，不把所有修改都归为错误。

| 日期 | 来源或作品 | 我的原表达/漏听位置 | 类型与原因 | 修正及依据 | 我的新例句/重练任务 | 复习日期与结果 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

类型可选：发音、听辨、词汇、语法、信息遗漏、组织表达。若只是另一种正确写法，注明“可选风格修改”。

复习时先遮住修正内容，自己修改，再换一个句子或片段检验；不必背整张表。反复出现的同类错误可合并为一个训练主题。
